# Site Daisy e Vinícius — Versão 5.3 — Traje sugerido

Seção **Trajes** adicionada imediatamente após **O grande dia** e incluída no menu do site.

**Convidadas** — “Sugerimos vestido longo. Com carinho, pedimos que evitem os tons rosa e fúcsia.”

**Convidados** — “Sugerimos traje social ou esporte fino.”

As ilustrações são originais e foram colocadas nos arquivos `public/assets/traje-convidadas.webp` e `public/assets/traje-convidados.webp`. O fundo do site permanece neutro para leitura, com o fúcsia como cor da decoração. Não foram alterados os pagamentos, o painel, o Pix, os convites ou as integrações.

## Publicar

Suba a pasta completa no Netlify (com a raiz `netlify.toml`). Se o site já estiver no ar, faça um novo deploy; não é preciso alterar o Supabase apenas para esta seção.
