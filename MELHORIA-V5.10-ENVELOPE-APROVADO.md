# V5.10 — Capa fiel à referência aprovada

A capa agora utiliza diretamente a arte de envelope enviada/aprovada pelo usuário: orquídeas fúcsia, textura original do papel, monograma D&V, lacre e botão *Toque para abrir*. A versão V5.9 utilizava formas CSS genéricas e diferia visualmente.

O nome mostrado ao convidado continua sendo uma camada de texto dinâmica, **nome principal + “e família”**, sem expressão “Com amor” e sem número de pessoas autorizadas. A imagem base foi recortada para retirar o mockup do telefone, preservando o envelope.

A animação cinematográfica permanece em fases: luz no lacre, dobras abrindo, transição e convite interno. Mantém Pular, Repetir, RSVP, Maps e calendário.

Para prévia: `convite-interativo.html?demo=1&nome=Daniel`. Após ativar a API de convites, o nome virá da família cadastrada pelo link exclusivo.

Validação local: prévia 390×844, recorte real de referência, nome dinâmico, animação de abertura, fechamento e JS sem erros de console. No iPhone, use a publicação HTTPS do Netlify para ver animações; arquivos locais HTML podem ser bloqueados pelo aplicativo.
